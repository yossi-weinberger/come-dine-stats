# בואו לאכול איתי — הדאטאבייס

## MVP

- Next.js 16 + TypeScript, RTL-first.
- חיפוש חופשי לפי שם, עיר, מקצוע ומנות.
- סינון לפי עונה ומנצחים.
- source badge בכל כרטיס מתמודד.
- `/sources` עם קרדיטים, רישיונות ומדיניות שימוש.
- Postgres/Supabase schema למתמודדים, שבועות, מנות, מקורות ו-field evidence.
- merge engine ששומר conflicts במקום לדרוס אותם.
- coverage report אוטומטי ב-`data/reports/coverage.json`.
- רענון יומי של מקורות בזמן שעונה 10 משודרת, כולל עדכון snapshot זה.

## עיקרון Source-first

אנחנו לא שומרים רק `value`; אנחנו שומרים גם מאיפה הוא הגיע. אם שני מקורות סותרים זה את זה, שתי העדויות נשמרות והסתירה נרשמת ב-`data/reports/conflicts.json`.

גם התאמת פרק רשמי למארח נבדקת: אם סדר האירוח ממקור מובנה סותר ניסוח אירוח מפורש של כאן, ההבדל נשמר בדוח `data/reports/kan-contestant-enrichment.json` במקום להיעלם.

### מקורות וקרדיטים

1. **בואו לאכול איתי — עונת הסטטיסטיקות / `nemo369`** — הפרויקט ההיסטורי שעזר להבין את מבנה הדאטה ואת ה-API הישן. לא נמצא רישיון מפורש בריפו ולכן לא מועתקים ממנו קוד, עיצוב או מדיה.
2. **Internet Archive / Wayback Machine** — שימש לניסיון שחזור ה-API הישן. ה-CDX ו-Availability API נבדקו; כרגע לא נמצא snapshot מסוג JSON-array ל-`contestants` או `weeks`. ה-manifest נשמר ב-`data/raw/legacy/wayback-manifest.json`.
3. **בואו לאכול איתי Wiki ב-Fandom** — מקור עיקרי לפרופילי ותפריטי עונות 1–2. כל רשומה שומרת URL ישיר לדף המקור. טקסט wiki ב-Fandom הוא בדרך כלל CC BY-SA 3.0 אלא אם צוין אחרת; מדיה אינה בהכרח תחת אותו רישיון.
4. **ויקיפדיה העברית** — מקור מבני מרכזי לעונות 3–10: שבועות, סדר אירוח, ציונים, מנצחים ופרטי תחרות נוספים. הייבוא שומר revision ו-attribution ברמת השדה.
5. **כאן 11** — מקור רשמי למטא-דאטה של פרקים, סדר שידור וקישורי פרקים; עובדות פרופיל מפורשות מתיאורי הפרקים נכנסות רק בצורה שמרנית ועם מקור ישיר.
6. **מקורות משלימים מאומתים** — Foodik ו-REST משמשים למנות כשהכתבה מזהה במפורש את המארח ואת המנה; לא משלימים תפריטים מניחושים.

פירוט: `data/ATTRIBUTION.md`, `data/SOURCES.md`, `data/sources.json` וקבצי המחקר תחת `research/`.

## הרצה מקומית

```bash
npm install
npm run dev
```

## Pipeline

רענון מלא:

```bash
npm run import:all
```

או שלבים נפרדים:

```bash
npm run import:fandom
npm run import:wikipedia
npm run import:season10
npm run import:kan
npm run enrich:kan-cities
npm run import:supplemental-menus
npm run merge
npm run coverage
npm run stats
npm run update:readme-stats
```

ניסיון שחזור היסטורי:

```bash
npm run recover:legacy
```

ה-GitHub Action ב-`.github/workflows/data-import.yml` מריץ את הייבוא אוטומטית, מייצר coverage report, מעדכן את snapshot ב-README ומבצע commit רק אם הדאטה השתנה.

## השלב הבא

- להעמיק את כיסוי הפרופילים — בעיקר גיל, מקצוע ועיר — ממקורות מפורשים בלבד.
- להרחיב כיסוי מנות לעונות 3–10 בלי להסיק תפריטים ממידע חלקי.
- להמשיך את עונה 10 במצב rolling עד סיום השידור.
- לבנות דפי מתמודד/עונה/שבוע וסטטיסטיקות עשירות ושיתופיות.
- לחבר Supabase כשנרצה לעבור מ-JSON versioned למסד נתונים חי.
